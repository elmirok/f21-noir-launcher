# Privacy

F21 Noir is offline software. It does not request Internet access, send telemetry, display ads,
create accounts, or include Google/Firebase SDKs. It reads the list of launchable apps only to draw
the launcher and stores preferences in Android private app storage.

The normal Android `SET_WALLPAPER` permission is used only when the user selects the local Noir
lock-screen wallpaper or restores the ROM wallpaper. The image is bundled in the APK; nothing is
downloaded or transmitted.

No personal data is collected by the project. GitHub downloads and issue submissions are governed
by GitHub's own policies.
