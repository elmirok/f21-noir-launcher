# Physical keys

| Key | Home action |
|---|---|
| D-pad | Move focus |
| Center | Open focused item |
| Menu | Open all apps |
| Long Menu | Open F21 Noir settings |
| Call | Open dialer |
| Short 0–9, `*`, `#` | Open dialer with character |
| Long 0–9 | Open configured shortcut |
| Back | Return to home |

The final keycode table must be verified on the physical `k61v1_64_bsp` device before beta.
